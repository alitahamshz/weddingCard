# کارت دعوت عروسی آرزو و علی 💌

یک کارت دعوت عروسی اینترنتی با **Next.js**، راست‌چین و فارسی، با تم **سفید و طلایی**
لاکچری.

## امکانات

- **دعوت‌نامه سه‌لتی (تاشو)**: در ابتدا دو لت بسته با مهر طلایی برجسته وسط دیده می‌شود؛
  با اسکرول، لت‌ها به دو طرف باز می‌شوند و اسم عروس و داماد نمایان می‌شود
- **کارت دعوت** با قاب و نقوش سنتی
- **شمارش معکوس** زنده تا روز مراسم
- **کارت اختصاصی هر مهمان** با لینک `/?guest=شناسه` (نام مهمان روی پاکت و کارت) + **پنل مدیریت رمزدار** (`/admin`) برای ساخت لینک و ارسال آن
- **جزئیات مراسم**: تاریخ، ساعت، مکان + دکمه مسیریابی روی نقشه
- **برنامه شب عروسی** (خط زمانی)
- **فرم اعلام حضور (RSVP)** مهمانان
- **موزیک پس‌زمینه** با دکمه پخش/توقف
- بارش گلبرگ، کاملاً ریسپانسیو (موبایل و دسکتاپ)

## اجرا

```bash
cd wedding-invitation
npm install
npm run dev
```

سپس مرورگر را روی `http://localhost:3000` باز کنید.

## شخصی‌سازی (مهم‌ترین بخش!)

همه اطلاعات در **یک فایل** قرار دارد — کافی است آن را ویرایش کنید:

📄 [`src/lib/config.ts`](src/lib/config.ts)

| فیلد | توضیح |
|---|---|
| `bride` / `groom` | نام عروس و داماد |
| `dateISO` | تاریخ و ساعت دقیق مراسم (برای شمارش معکوس)، مثلاً `2027-01-08T18:00:00+03:30` |
| `dateFa` / `timeFa` | تاریخ و ساعت نمایشی، مثلاً `جمعه ۱۸ دی ۱۴۰۵` |
| `venue` | نام تالار یا محل برگزاری |
| `address` | آدرس کامل |
| `mapUrl` | لینک گوگل‌مپ برای دکمه مسیریابی |
| `schedule` | برنامه‌های شب عروسی (ساعت، عنوان، توضیح) |

## گذاشتن آهنگ دلخواه

به‌صورت پیش‌فرض یک موزیک ملایم داخلی پخش می‌شود. برای استفاده از آهنگ خودتان،
کافی است فایل آن را با نام **`music.mp3`** داخل پوشه **`public`** بگذارید:

```
wedding-invitation/
└── public/
    └── music.mp3   ← آهنگ شما
```

## انتشار در اینترنت (رایگان)

راحت‌ترین راه، **Vercel** است:

1. پروژه را در گیت‌هاب آپلود کنید
2. در [vercel.com](https://vercel.com) با گیت‌هاب وارد شوید
3. پروژه را Import کنید و Deploy بزنید

بعد از چند دقیقه یک لینک مثل `wedding-invitation.vercel.app` می‌گیرید که
می‌توانید برای مهمان‌ها بفرستید.

## نکته درباره فرم اعلام حضور

در حال حاضر پاسخ مهمان‌ها فقط در مرورگر خودشان ذخیره می‌شود (نسخه نمایشی).
اگر بخواهید پاسخ همه مهمان‌ها یکجا جمع شود، می‌توان یک بک‌اند ساده
(مثلاً با Google Sheets یا Supabase) به آن وصل کرد.

## کارت اختصاصی مهمان‌ها و پنل مدیریت

این دعوت‌نامه قابلیت ساخت کارت اختصاصی برای هر مهمان را دارد:
- اگر مهمان آدرس عمومی را باز کند (`/`)، متن پیش‌فرض نمایش داده می‌شود.
- اگر آدرس با پارامتر مهمان باز شود (مثلاً `/?guest=pedram`):
  - روی لبهٔ سمت چپ پاکت، عنوان «دعوت‌نامه‌ای برای [نام مهمان]» درج می‌شود.
  - بالای کارت دعوت، عبارت «تقدیم با احترام به [نام مهمان]» با سقف همراهان نشان داده می‌شود.
  - در فرم اعلام حضور (RSVP)، نام مهمان به‌صورت خودکار پر شده و گزینه‌های تعداد نفرات متناسب با سقف تعیین‌شده تنظیم می‌گردند.
  - تگ سئوی `noindex` فعال می‌شود تا لینک‌های اختصاصی در موتورهای جستجو ثبت نشوند.

### ورود به پنل مدیریت (`/admin`)

1. رمز عبور پیش‌فرض در فایل `.env.local`: `wedding1405`
2. برای تغییر رمز، مقدار `ADMIN_PASSWORD` را در `.env.local` یا تنظیمات هاست (مثلاً Vercel Environment Variables) تغییر دهید.
3. در آدرس `http://localhost:3000/admin` وارد شوید:
   - افزودن، ویرایش و حذف مهمان‌ها با تولید خودکار اسلاگ انگلیسی.
   - کپی لینک اختصاصی با یک کلیک.
   - کپی متن آمادهٔ دعوت یا باز کردن مستقیم در واتس‌اپ.
   - دکمهٔ «ذخیره در فایل سایت» در محیط لوکال فایل `src/data/guests.json` را به‌روزرسانی می‌کند.
   - دکمه‌های «دانلود فایل پشتیبان (JSON)» و «بارگذاری فایل» برای هاست‌های Serverless (مثل Vercel) که دیسک فقط‌خواندنی دارند.
   - شماره تلفن و یادداشت خصوصی فقط در مرورگر شما نگه‌داری می‌شوند و هرگز در فایل نهایی سایت یا بسته‌های پابلیک ذخیره نمی‌گردند.
